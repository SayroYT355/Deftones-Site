Sobre el Creador del Proyecto

Mi nombre es Angel De Piero, estudiante del último año de la carrera técnica en Informática. Este sitio web dedicado a Deftones fue desarrollado íntegramente por mí como un proyecto práctico y técnico para la materia de desarrollo y maquetación web, aplicando estándares modernos de HTML5, CSS3 y JavaScript.

El objetivo principal de este espacio es demostrar de forma práctica el manejo correcto de las jerarquías de texto, menús de navegación enlazados, aplicación de etiquetas de formato especial y la estructuración limpia de código utilizando Visual Studio Code.
